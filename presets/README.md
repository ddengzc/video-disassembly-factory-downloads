## 文件与同步

- catalog.source.json：可读的配置原文，供维护与审阅。
- catalog.json：应用实际读取的 RSA/SHA-256 签名信封；payload 为原始 JSON 字节的 Base64。
- versions/1.0.0.json：本版签名配置留档；不覆盖历史版本。
- history.json：预设版本、revision、摘要及验证范围。

软件每次启动后台检查一次，也可在模板分类或配音音色页面点击“检查更新”。不需要重新下载安装应用。网络或校验失败继续使用本地有效缓存；当前配置中的旧条目变化时需重新选择，已开始任务使用原快照。

## 后续修改

只能修改公共预设字段；不得加入 API 密钥、Cookie、GitHub Token 或任何签名私钥。维护者修改可读配置后须递增 revision 和版本，使用私有源码仓库 tools/sign_catalog.py 在本地签名并验证，再同时提交可读配置、签名文件、版本留档和历史记录，通过 PR 合并。直接编辑可读配置不会被应用采用；改动签名 payload 而不重新签名会被客户端拒绝。

发布私钥必须由维护者单独保管，不能上传本仓库。客户端的公钥固定在应用内，不能通过替换远端文件改变客户端信任。应用版本、组件版本与预设版本分别管理；本次仅发布预设，不修改应用和组件附件。
