# 视频拆解工厂 · 开整

Apple Silicon / macOS 14.2+ 的本地视频模板工作台。

## V3.0 下载验收

- [下载开整 V3.0](https://github.com/ddengzc/video-disassembly-factory-downloads/releases/tag/v3.0.0)
- [固定运行组件与模型](https://github.com/ddengzc/video-disassembly-factory-downloads/releases/tag/components-v2.0.0)

V3.0 先按预发布提供下载与实际使用验收。原应用、旧标签和旧组件保留，等用户确认 V3.0 下载、打开和实际处理正常后再处理旧版本；仍被保留版本引用的组件不删除。

解压后打开“开整.app”。已有用户会复用原工作目录、组件与任务资料；首次使用需在设置中安装 8 项固定组件（约 1.22 GB，不再下载本地标点模型），程序按 SHA-256 和逐文件清单校验。保留旧应用可用于回退，不删除工作目录。

本版本将补标点与完整意思语义分段合并为一次文案模型请求，保留完整转写与字词时间戳；确认页左侧固定视频、修复封面与统计布局，安装完成后统一校验并允许扫码并行保存凭据，移除离线导入入口，手动 Cookie 平铺。源码和自动化检查记录保存在项目维护仓库，下载包不包含用户任务、Cookie 或 API 密钥。

本地 ad-hoc 签名，未做 Developer ID 公证。新 Mac 首次启动可能需要通过 macOS 的正常允许流程；用户仍需验收真实视频处理和外部后台导入。问题反馈请附操作步骤及脱敏截图，不上传凭据或私有视频。
